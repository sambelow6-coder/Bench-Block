# Block summaries

One file per finished 4-week block: `block-<N>.md`. Written by the coach at the
end of a block so old training doesn't have to be re-read row by row every week.

Each summary carries what the next decision actually needs:

- **e1RM trend per lift** — start, end, weekly bests
- **Best sets** — the top single, double, triple and five at any point
- **Volume** — weekly tonnage and hard sets for the main lifts, hard sets per muscle
- **RPE drift** — average RPE at each prescribed percentage, week by week
- **Pain / rehab** — check-in scores against load, and what the gate allowed
- **Adherence** — sets done vs prescribed, and every skip reason
- **Rulings** — what changed in the program and why

The raw log stays in the Google Sheet forever; these files are the compact
memory. The weekly check-in reads recent weeks in full plus these summaries.
